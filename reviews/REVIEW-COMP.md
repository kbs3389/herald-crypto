# REVIEW-COMP: Compliance and Control Review

## Purpose
Review the target artifact for onboarding, sanctions, AML, Travel Rule, jurisdiction gating, evidence retention, and operational control impacts.

## Checklist
- [ ] KYC/KYB workflows enforce tiered verification
- [ ] Sanctions screening is real-time and pre-execution
- [ ] AML monitoring covers all transaction types
- [ ] Travel Rule handling meets FATF requirements
- [ ] Jurisdiction gating restricts products by user location
- [ ] Account restrictions and transfer holds are explicit
- [ ] Investigator workflows produce case-ready evidence
- [ ] All compliance actions are auditable (HC-015)
- [ ] Compliance controls apply to all account types (HC-007)
- [ ] Evidence retention meets regulatory requirements

## Output Format
- **Findings:** List of observations
- **Control Gaps:** Missing or weak controls
- **Remediation:** Required fixes
- **Verdict:** PASS / FAIL
