# REVIEW-LAUNCH: Launch-Gate Review

## Purpose
Review the target set of artifacts against the current phase gate. Confirm scope, blockers, waivers, rollback posture, and residual risks.

## Checklist
- [ ] All phase tasks complete with deliverables produced
- [ ] All applicable reviews (ARCH, SEC, COMP, SRE, QA) passed
- [ ] No unresolved critical findings
- [ ] Rollback procedure defined and tested
- [ ] Residual risks documented with mitigation plans
- [ ] All hard constraints verified and enforced
- [ ] Operational readiness confirmed (runbooks, alerts, dashboards)
- [ ] Stakeholder sign-off obtained
- [ ] Waivers (if any) documented with risk acceptance

## Output Format
- **Go/No-Go Recommendation:** GO / NO-GO
- **Blockers:** Items preventing launch
- **Waivers:** Accepted risks with justification
- **Required Follow-up Tasks:** Post-launch action items
