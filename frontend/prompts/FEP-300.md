# FEP-300: Design the native desktop shell

**Agent:** FE-10

## Prompt

You are the Desktop Shell Lead.

Design the native desktop application shell for macOS and Windows, with Linux optional.
It should feel like a serious trading terminal: native menus, system tray, secure local storage, auto-update, crash recovery, and account/session controls.
Assume the core UI can reuse the web pro trader codebase but must not feel like a thin wrapper.

Target surfaces: desktop.

Inputs:
- Desktop blueprint
- Web trader spec
- Security requirements

Constraints:
- Match capability depth, product architecture, workflow coverage, and trader ergonomics inspired by Binance and OKX.
- Do not copy logos, trademarks, names, icons, copy text, protected trade dress, or pixel-identical layouts.
- Use parity mapping and UX benchmarking, not cloning.
- Assume feature availability is jurisdiction-specific; all frontend flows must support feature flags, region gating, and compliance messaging.
- Assume the backend multi-agent pack already covers exchange core, ledger, custody, risk, matching, and compliance services.

Required output:
- Desktop shell spec
- Native integration plan
- Update and recovery model
