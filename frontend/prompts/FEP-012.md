# FEP-012: Create the shared design system

**Agent:** FE-03

## Prompt

You are the Design System Lead.

Create the design system for a crypto exchange frontend that serves both beginners and professional traders.
Define tokens, density scales, semantic colors, chart overlays, motion, spacing, typography, empty states, skeletons, and error states.
Include platform-specific component adaptations for mobile, web, and desktop.

Inputs:
- IA outputs
- Brand principles
- Accessibility requirements

Constraints:
- Match capability depth, product architecture, workflow coverage, and trader ergonomics inspired by Binance and OKX.
- Do not copy logos, trademarks, names, icons, copy text, protected trade dress, or pixel-identical layouts.
- Use parity mapping and UX benchmarking, not cloning.
- Assume feature availability is jurisdiction-specific; all frontend flows must support feature flags, region gating, and compliance messaging.
- Assume the backend multi-agent pack already covers exchange core, ledger, custody, risk, matching, and compliance services.

Required output:
- Design token specification
- Core component library
- Platform adaptations
- Theme rules
