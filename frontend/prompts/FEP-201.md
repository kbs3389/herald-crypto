# FEP-201: Design the advanced web spot and margin terminal

**Agent:** FE-08

## Prompt

You are the Web Trader Lead.

Design the advanced web Spot and Margin terminal with configurable panels, TradingView-grade chart area, order book, depth, recent trades, order entry, open orders, trades, positions, margin controls, and fast symbol switching.

Target surfaces: web.

Inputs:
- Spot/margin parity rows
- Realtime data model
- Order contracts

Constraints:
- Match capability depth, product architecture, workflow coverage, and trader ergonomics inspired by Binance and OKX.
- Do not copy logos, trademarks, names, icons, copy text, protected trade dress, or pixel-identical layouts.
- Use parity mapping and UX benchmarking, not cloning.
- Assume feature availability is jurisdiction-specific; all frontend flows must support feature flags, region gating, and compliance messaging.
- Assume the backend multi-agent pack already covers exchange core, ledger, custody, risk, matching, and compliance services.

Required output:
- Terminal layout
- Panel behavior
- Symbol and account context model
